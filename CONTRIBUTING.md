# Contributing

This repository is one component of Chronicle and is published as part of the
[uzaira0/methodic](https://github.com/uzaira0/methodic) root repository, which pins it as a
submodule. The history here is curated at publish time; development happens in
a private repository and accepted pull requests are integrated there with authorship
preserved, then carried here by the next publish.

Read the root [CONTRIBUTING.md](https://github.com/uzaira0/methodic/blob/main/CONTRIBUTING.md)
for the workflow, the local checks to run, and commit conventions, and the root
[docs/GIT-WORKFLOW.md](https://github.com/uzaira0/methodic/blob/main/docs/GIT-WORKFLOW.md)
for the branching and publishing model. Security reports go through GitHub's private
vulnerability reporting on this repository; see [SECURITY.md](SECURITY.md).
